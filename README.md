# Husni Zayyin Ansori — Interactive 3D Engineering Portfolio

Personal portfolio of **Husni Zayyin Ansori (Husni Zayn)** — Senior Software Engineer & System Architect based in Jakarta, Indonesia (`UTC+7`) with 5+ years of remote and enterprise experience across **Next.js, Flutter, React, Laravel, and PostgreSQL**.

## Core Architecture

- **Framework & Styling**: Next.js 14 (App Router), TypeScript, Tailwind CSS (`class` dark-mode strategy, pure `#FFFFFF` Light Mode default).
- **Interactive WebGL 3D**: **React Three Fiber (`@react-three/fiber`)**, **`@react-three/drei`**, and **Three.js** powering the interactive *Architectural Prism & Kinetic Core* hero sculpture (`Prism`, `Lattice`, and `Kinetic` modes, cursor magnetism, click resonance, and procedural studio lighting).
- **Motion Choreography**: **Framer Motion** (`layoutId` shared-element pills, scroll-scrubbed manifesto typography, expandable architectural case-study modals, and spring physics).
- **Zero-Delay Auditory Feedback**: **`use-sound`** backed by preloaded 44.1kHz PCM WAV buffers (`public/sounds/`) for instantaneous, non-blocking tactile feedback on buttons, navigation, theme switches, drawers, and 3D interactions.
